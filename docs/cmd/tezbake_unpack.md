Unpack a merged tezbake archive

### Synopsis

Overlays an archive created by 'tezbake pack' onto an existing setup, like an upgrade. Every app in the archive must already be installed: run 'tezbake setup' first, locally or with --node-remote, then unpack. Data (chain data, keys, configuration) comes from the archive; data not in the archive (e.g. chain data excluded from a pack) is kept. The installation keeps its identity and wiring: app id, user, remote connection and the signer node connection. Running apps are stopped during the restore and started again after it succeeds; apps that were not running stay stopped until 'tezbake start'. Before changing anything, unpack asks you to confirm that every other instance of these apps is stopped and removed, because two instances baking with the same keys double bake; --confirm skips the prompts.

```
tezbake unpack [flags]
```
